### 2.1 Что уже сделано хорошо (не переделывать)

- `robots.txt` + `sitemap.xml` есть, `robots.txt` ссылается на sitemap.
- 21 страница (главная + `fractions` 8 + `percents` 5 + `divisibility` 4 + `equations` 3) имеет полный SEO-блок: `title`, `description`, `keywords`, `author`, `robots`, `canonical`, OG, JSON-LD `LearningResource`.
- На главной — JSON-LD `Course` + `FAQPage`, канонический URL без `index.html`.
- Яндекс.Метрика (`assets/analytics.js`, id 106746549) стоит на всех страницах — данные для замера уже собираются.
- Есть готовый сниппет иконок `head-snippet.html` — новые страницы копируют его.

### 2.2 Что мешает именно ВПР-кластеру

1. **Нет посадочной страницы.** Сам тренажёр ВПР живёт в своём репозитории `vpr-math-6` (наш проект: отдельная индексация, отдельная Метрика 107714636), и с `math-6-grade` на него ведёт одна ссылка в карточке главной. По запросу «подготовка к ВПР по математике 6 класс» `math-6-grade` нечего показать, кроме главной про тренажёры, а у `vpr-math-6` — только интерфейс тренировки: ни текста, ни `canonical`, ни обратных ссылок.
2. **Нет «толкового» текста.** 39 из 42 страниц — интерфейс без объяснений: поисковику нечего ранжировать по информационным запросам («как найти НОК 6 класс», «типы заданий ВПР 6 класс»).
3. **Нет навигации в HTML.** Ссылка «🏠 Меню» на главную создаётся скриптом (`assets/analytics.js`), а не разметкой: в HTML ссылку на главную содержит только `privacy.html`. Пользователь из поиска попадает на тренажёр и не может уйти в другие темы, краулер не видит связей.
4. **`sitemap.xml` рассинхронизирован:** нет `fractions/conversion.html`, `percents/tiles.html`, `privacy.html`; зато есть запись `vpr-math-6/index.html` — это **свой** отдельный проект (`github.com/godspace/vpr-math-6`), но в sitemap `math-6-grade` он всё равно невалиден: sitemap перечисляет только URL своего хоста (поиск считает такую запись ошибкой).
5. **`og:image` нет нигде** — низкий CTR при пересылке ссылок в чатах (учителя делятся ссылками именно так).

## 3. Границы (что в этой ревизии не делаем)

- Не трогаем логику тренажёров (`assets/*.js`, inline-JS задач), `math_board`, Firebase-слой, структуру `localStorage`.
- Не меняем URL существующих страниц (нет 301 на GitHub Pages → переезды запрещены).
- Не покупаем ссылки, не клоачим, не генерим «SEO-текст» без смысла.
- Не копируем дословно задания ФИПИ/демоверсии: только свои формулировки + ссылка на официальный источник.
- Не дублируем контент между `math-6-grade` и `vpr-math-6`: у проектов разные задачи (тренажёры по темам vs вариант ВПР).
- SEO самого `vpr-math-6` (`github.com/godspace/vpr-math-6` — свой проект, отдельный репозиторий и отдельная Метрика 107714636) — **отдельная задача**: здесь только ссылка/перелинковка с ним, его `canonical`/OG/JSON-LD/текст не правим.

### 6.3 S3 — витрина ВПР `trainers/vpr/index.html` (главный шаг)

**Решение от 2026-11-18: `math-6-grade` — витрина, `vpr-math-6` — сам тренажёр.** Два сайта одного владельца не должны целиться одним `<h1>` в один запрос, иначе поиск выберет один и отфильтрует второй. Разделяем по интенту:

| сайт | интент / запросы | `title` (ориентир) | что делает |
|---|---|---|---|
| `math-6-grade/trainers/vpr/` | «подготовка», «что входит», «сколько баллов», «как готовиться», «задания по темам» | Подготовка к ВПР по математике 6 класс: темы, баллы, план | объясняет и разводит по тренажёрам, ведёт на вариант |
| `vpr-math-6/` | «решать», «вариант», «тренажёр», «с ответами» | ВПР по математике 6 класс — решать вариант онлайн | даёт интерактивный вариант (17 заданий, 23 балла) |

Ссылки — с разными анкорами: с витрины «решать вариант онлайн →», с тренажёра «← подготовка и разбор тем». Так витрина передаёт вес тренажёру, а тренажёр не конкурирует с витриной по слову «подготовка».

Структура страницы (объём 800–1200 слов — это то, чего сейчас нет нигде на сайте):

1. `H1`: «Подготовка к ВПР по математике 6 класс» (ровно один H1).
2. Лид 2–3 предложения: что за работа, сколько времени, что проверяет, чем помогает сайт.
